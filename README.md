# Doctor Tracker

Admin UI for doctors, patients, and the dashboard. This folder is the Next.js app. The API is a separate Express server.

## Run

1. Copy `.env.example` to `.env`.
2. `npm install`
3. `npm run dev`

`/api/*` is rewritten to `API_URL` (default `http://localhost:4000`). The full setup guide, architecture, and screenshots land in the documentation step.
